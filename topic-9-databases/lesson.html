9.1 · Database structure · 01

Fields, records and tables

  • A row stores one record.
  • A column holds one field across all records.
  • A table describes one type of entity.
Check your understanding

In a BOOK table, is Price a field or a record?

Show model answer

A field. A complete row describes one book.

9.3 · Primary keys · 05

Primary keys

  • Every record needs a unique key value.
  • Choose a stable identifier rather than a name that may repeat.
  • A key must not be missing.
Check your understanding

Why is Title a poor primary key?

Show model answer

Different books or editions can share a title. BookID can be assigned a unique value to each record.

9.4 · Select and filter · 08

SELECT, FROM and WHERE

  • FROM names the single source table.
  • WHERE tests each record against a condition.
  • Text values need quotation marks.
SELECT Title, Price
FROM BOOK
WHERE InStock = TRUE;

9.4 · Sort · 11

Filtering and sorting

  • ORDER BY specifies the sorting field and direction.
  • The field used for sorting need not be displayed.
  • Cambridge uses ASCENDING / DESCENDING; SQLite uses ASC / DESC.
SELECT Title, Price
FROM BOOK
WHERE InStock = TRUE AND Price >= 10
ORDER BY Price DESCENDING;
Check your understanding

Which title appears first?

Show model answer

Databases (15), then Algorithms (12). Programming is excluded because InStock is FALSE.

9.4 · Compound conditions · 13

AND, OR and parentheses

  • AND requires both conditions. OR requires at least one.
  • Parentheses make the intended grouping clear.
  • Read the Boolean condition for each record before selecting it.
SELECT BookID
FROM BOOK
WHERE InStock = TRUE
AND (Price < 10 OR Price > 14);
Check your understanding

Which BookIDs match?

Show model answer

B03 and B04. B02 meets Price > 14 but fails the stock condition.

9.4 · Aggregates · 15

COUNT and SUM

  • COUNT(*) counts matching records.
  • SUM(Price) adds the numeric Price values of matching records.
  • An aggregate query produces a summary result.
SELECT COUNT(*) FROM BOOK
WHERE InStock = TRUE;

SELECT SUM(Price) FROM BOOK
WHERE InStock = TRUE;
Check your understanding

What are the two results for the BOOK data?

Show model answer

COUNT(*) = 3; SUM(Price) = 36. COUNT(Price) counts non-null Price values rather than adding them.
