Part 1: Single-Table Databases

1. Introduction to Databases

  • A database  is a structured collection of data that allows people to extract information in a way that meets their needs. Suitable keys, validation and careful design help reduce unwanted duplication and improve consistency.
  • For the IGCSE syllabus, you only need to study single-table databases  (a database that contains only one table).

2. Fields and Records

Data inside a database table is structured into records  and fields :

  • Table:  Contains data about one type of item, person, or event (e.g., a PATIENT table or a BOOK table).
  • Record (Row):  Each row in the table is a record. A record contains data about a single  item, person, or event (e.g., all the details about one specific patient).
  • Field (Column):  Each column in the table is a field. A field contains a specific piece of information  about the item in the record (e.g., FirstName, FamilyName, DateOfAdmission). Every record in the table contains the exact same number of fields.

3. Validation

  • Validation  is the automated checking by a program to ensure that data is reasonable and allowable before it is accepted and stored in the database.
  • Common validation rules applied to fields include:
  • Presence check:  Ensuring a field cannot be left blank.
  • Range check:  Ensuring numbers fall within a specific range (e.g., Ward number must be between 1 and 10).
  • Length check:  Ensuring a certain number of characters is entered.
  • Type check:  Ensuring the data entered matches the required data type.

Part 2: Basic Data Types

When creating a database, every field must be assigned a specific data type . This classifies how the data is stored, displayed, and what operations can be performed on it. The six basic data types you must know are:

  1. Text / Alphanumeric:  A sequence of characters, which can include letters, numbers, and symbols (e.g., "123 Main Street", "John").
  2. Character:  A single character or symbol (e.g., 'M', 'F', 'Y').
  3. Boolean:  A data type that can only hold one of two possible values (e.g., TRUE or FALSE, 1 or 0, Yes or No).
  4. Integer:  A whole number (positive, negative or zero) that can be used in mathematical calculations (e.g., 25, -10).
  5. Real:  A decimal number / a number capable of a fractional part (e.g., 3.14, 12.50).
  6. Date / Time:  A specific format for storing dates and/or times (e.g., 22/11/2022, 15:45:00).

Part 3: Primary Keys

1. Purpose of a Primary Key

  • A primary key  is a unique field that uniquely identifies each individual record in a database table.
  • Crucial Rule:  A primary key must contain data values that are never repeated  in the table.

2. Identifying a Suitable Primary Key

  • When looking at a table, fields like FirstName or DateOfBirth cannot be primary keys because two people could share the same name or birthday.
  • A suitable primary key is usually an ID number or a unique code (e.g., Student_ID, Passport_Number, ISBN for a book, or an auto-generated HospitalNumber like HN123456).

Part 4: Structured Query Language (SQL)

SQL (Structured Query Language)  is the standard programming language for writing scripts to query (search and extract) useful information from a database.

1. Key SQL Commands

You must be able to read, complete, and understand SQL scripts using the following commands:

  • SELECT : Fetches and displays specified fields (columns) from a table. Queries always begin with SELECT. (Using SELECT * means "select all fields").
  • FROM : Identifies the table you want to extract data from.
  • WHERE : Filters the data to include only the records (rows) that match a given condition.
  • AND / OR : Used within the WHERE clause to combine multiple conditions.
  • ORDER BY : Sorts the results of the query by a specific column.
  • ORDER BY ASCENDING (or ASC) : Sorts alphabetically (A-Z) or numerically (smallest to largest).
  • ORDER BY DESCENDING (or DESC) : Sorts in reverse alphabetical (Z-A) or reverse numerical order.
  • SUM : Returns the mathematical total of all values in a specific numeric field. (Used alongside SELECT, e.g., SELECT SUM(Price)).
  • COUNT : Counts the total number of records (rows) that match a specified condition. (Used alongside SELECT, e.g., SELECT COUNT(StudentID)).

2. Formatting Data in SQL

When writing conditions in a WHERE statement, data types must be formatted correctly:

  • Text/Character:  Enclosed in single or double quotes (e.g., WHERE Consultant = 'Mr Smith').
  • Number (Integer/Real):  Written plainly without quotes (e.g., WHERE WardNumber = 7).
  • Boolean:  Written as TRUE or FALSE (e.g., WHERE SoldOut = TRUE).

3. Example SQL Scripts

Example A: Simple Selection and Sorting To show the HospitalNumber, FirstName, and FamilyName of all patients cared for by 'Mr Smith', sorted alphabetically by their family name: 

SELECT HospitalNumber, FirstName, FamilyName
FROM PATIENT
WHERE Consultant = 'Mr Smith'
ORDER BY FamilyName ASCENDING;

Example B: Using AND / OR To select all cars that have red seats AND either white or silver paint: 

SELECT Code
FROM CAR
WHERE SeatColour = 'Red' AND (PaintColour = 'White' OR PaintColour = 'Silver');

Example C: Using COUNT To count how many records exist for patients located in Ward 7: 

SELECT COUNT(HospitalNumber)
FROM PATIENT
WHERE WardNumber = 7;

Revision Tips:

  • Always ensure your SQL scripts end with a semicolon (;) if writing them out, and always check that string/text criteria are enclosed in quotes ''.
  • Be ready to look at a given database table and write down the exact output  a specific SQL statement will produce.
  • Be prepared to look at a set of data storage requirements and suggest the most appropriate data type  and primary key .
