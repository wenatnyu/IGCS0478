BookID is the primary key; Title uses text, Price uses real, and InStock uses Boolean. A row is one book record and a column is one field.

Select, filter and sort

SELECT Title, Price
FROM BOOK
WHERE InStock = TRUE AND Price >= 10
ORDER BY Price DESCENDING;

The syllabus uses ASCENDING and DESCENDING. Many SQL systems use the shorter keywords ASC and DESC.

Summarise records

SELECT SUM(Price) FROM BOOK WHERE InStock = TRUE;
SELECT COUNT(*) FROM BOOK WHERE InStock = TRUE;

The first result is 36; the second is 3. SUM adds numeric values; COUNT(*) counts matching rows. COUNT(Field) counts non-null values in that field.

Group alternatives

SELECT BookID FROM BOOK
WHERE InStock = TRUE AND (Price < 10 OR Price > 14);

Matching IDs are B03 and B04; without ORDER BY, a particular row order is not guaranteed. Parentheses make the alternatives apply together with the stock condition.
