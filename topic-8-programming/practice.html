8.1 · A function with selection

FUNCTION Result(Mark : INTEGER) RETURNS STRING
    IF Mark >= 50
      THEN
        RETURN "Pass"
      ELSE
        RETURN "Retry"
    ENDIF
ENDFUNCTION
OUTPUT Result(72)

Output: Pass. Mark is a parameter local to the function. A procedure performs a task; a function returns a value that can be used in an expression.

8.2 · Populate a 2D array

DECLARE Marks : ARRAY[1:2, 1:3] OF INTEGER
FOR Student ← 1 TO 2
    FOR Test ← 1 TO 3
        OUTPUT "Enter mark for student ", Student, " test ", Test
        INPUT Marks[Student, Test]
    NEXT Test
NEXT Student

Six inputs fill two rows and three columns. The outer loop chooses the student; the inner loop visits each test. Keep every index within the declared bounds.

8.3 · Write and read a line

DECLARE Message : STRING
OPENFILE "message.txt" FOR WRITE
WRITEFILE "message.txt", "Hello"
CLOSEFILE "message.txt"
OPENFILE "message.txt" FOR READ
READFILE "message.txt", Message
CLOSEFILE "message.txt"
OUTPUT Message

Output: Hello. Files retain data after the program ends. WRITE replaces existing file contents. Always close the file when finished.

Combine arrays and subroutines

Store five marks in a 1D array. Write a function that returns the number of marks greater than or equal to 50.

Reveal solution guidance

Use ARRAY[1:5] OF INTEGER. Initialise Count to 0, loop through every element, increment Count when the mark is >= 50, and RETURN Count. For [49, 50, 100, 0, 75], return 3. Use meaningful names and keep the counter local to the function.
