8.1 Programming Concepts

1. Variables and Constants

  • Variable:  A named data store that contains a value that may change during the execution of a program.
  • Constant:  A named data store containing a value that does not change during the execution of a program.

2. Basic Data Types

Data types classify how data is stored, manipulated, and displayed. The basic data types you must know are:

  • INTEGER:  A whole number (positive, negative or zero).
  • REAL:  A positive or negative number with a fractional (decimal) part.
  • CHAR:  A single character.
  • STRING:  A sequence of characters. It can vary in length, include letters, digits, or symbols, and can even be empty.
  • BOOLEAN:  A logical value that can only be TRUE or FALSE.

3. Input and Output

  • Input:  Used for data entry. It is essential to provide a user prompt (a message) alongside an input so the user knows what data is expected.
  • Output:  Used to display information on a screen or print it on paper. An output statement can include a message to explain the result, and multiple parts can be separated by commas.

4. Core Programming Constructs

  • Sequence:  The exact order in which steps in a program are executed; an incorrect sequence can lead to logically incorrect results.
  • Selection:  Choosing different paths through a program depending on specific criteria.
  • IF Statements:  Used for single choices or alternatives (IF...THEN...ELSE...ENDIF).
  • CASE Statements:  Used when there are multiple choices based on the value of a single variable, making code cleaner than using many IFs (CASE OF...OTHERWISE...ENDCASE).
  • Iteration (Loops):  Repeating a section of programming code under certain conditions.
  • Count-controlled loops:  Used for a set number of repetitions (e.g., FOR...TO...NEXT).
  • Pre-condition loops:  The condition is tested before the loop starts. The number of repeats is unknown, and the loop may never be executed if the initial condition is false (e.g., WHILE...DO...ENDWHILE).
  • Post-condition loops:  The condition is tested at the end. The number of repeats is unknown, but the loop will always execute at least once (e.g., REPEAT...UNTIL).
  • Totalling and Counting:
  • Totalling:  Keeping a running total by adding values to a variable (e.g., Total = Total + Mark).
  • Counting:  Keeping track of the number of times an action is performed, usually incrementing by 1 (e.g., Count = Count + 1).
  • String Handling:
  • LENGTH:  Finds the number of characters in a string.
  • SUBSTRING:  Extracts a part of a string. (Format: SUBSTRING(identifier, start, length)) .
  • UPPER / UCASE:  Converts all letters in a string to uppercase.
  • LOWER / LCASE:  Converts all letters in a string to lowercase.
  • (Note: The first character of a string can be at position zero or one depending on the language) .

5. Operators

  • Arithmetic Operators:  Addition (+), Subtraction (-), Multiplication (*), Division (/), Raised to the power of (^), Remainder division (MOD), and Integer division (DIV).
  • Relational Operators:  Equal to (=), Less than (<), Less than or equal to (<=), Greater than (>), Greater than or equal to (>=), and Not equal to (<>).
  • Logical (Boolean) Operators:  AND (both true), OR (either true), and NOT (reverses truth value).

6. Nested Statements

  • Nesting is the inclusion of one type of code construct inside another, such as placing a selection statement within a loop, or a loop inside another loop. The syllabus requires you to understand up to three levels of nested statements.

7. Procedures, Functions, and Parameters

  • Procedures:  A set of programming statements grouped under a single name that can be called to perform a task anywhere in a program, saving code repetition.
  • Functions:  Similar to a procedure, but it strictly returns a single value back to the main program where it was called.
  • Parameters:  Variables in a procedure or function declaration that store the values of the arguments passed to them. Both procedures and functions may have up to three parameters.
  • Local vs. Global Variables:
  • Global Variable:  Declared at the start of a program, its scope covers the whole program.
  • Local Variable:  Declared inside a specific sub-routine (like a procedure or function), its scope is restricted solely to that part of the program.

8. Library Routines

Library routines are built-in, fully tested routines that perform common tasks. You must be able to use:

  • MOD:  Returns the remainder of a division.
  • DIV:  Returns the quotient (the whole number part) of a division.
  • ROUND:  Returns a value rounded to a specified number of decimal places.
  • RANDOM:  Generates a random number.

9. Creating a Maintainable Program

To ensure that a program can be easily understood, debugged, and updated by other programmers later, it must be maintainable. This is achieved by:

  • Using meaningful identifiers  for variables, constants, arrays, procedures, and functions.
  • Fully utilising the programming language's commenting  feature to explain the syntax and logic.
  • Dividing the program into modular tasks using procedures and functions .

8.2 Arrays

1. Declaring and Using Arrays

  • An array is a data structure containing several elements of the same data type , uniformly accessible via an index.
  • 1D Arrays (Lists):  A single-dimension list. When declaring it, you must state the name, the first and last index values, and the data type 37, 39. (Note: The first index can be zero or one) .
  • 2D Arrays (Tables):  Data is arranged in rows and columns. When declaring it, you specify the index bounds for both rows and columns.

2. Reading and Writing Arrays using Iteration

  • Arrays are populated and read using loop structures (iteration). A variable is used as the index to dynamically move through the array elements.
  • For 2D arrays, nested iteration  (a loop inside a loop) is required to track both the row and column coordinates.

8.3 File Handling

1. Purpose of Storing Data in a File

  • Any data stored in RAM is volatile and is lost when the computer is switched off.
  • Storing data in a file ensures it is saved permanently  to secondary storage so that it can be retrieved and used again by the same program or by other programs at a later date.

2. Operating on Files

  • Before a file can be read from or written to, it must explicitly be opened  (OPENFILE) with a specified file mode.
  • READ Mode:  Used to read single items of data or a full line of text from an existing file.
  • WRITE Mode:  Used to write single items of data or lines of text to a file. Opening a file in WRITE mode creates a new file, and any existing data in an older file with the same name will be lost.
  • Files must always be closed  (CLOSEFILE) when the program has finished with them.
