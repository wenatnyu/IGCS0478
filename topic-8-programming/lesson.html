8.1 · Data and declarations · 01

Variables, constants and data types

  • A variable can change; a constant retains its value.
  • Use meaningful identifiers and declare types explicitly in pseudocode.
TypeExample
INTEGER / REALCount = 5 / Mean = 12.4
CHAR / STRINGGrade = 'A' / Name = "Ada"
BOOLEANComplete = TRUE
Check your understanding

What type suits a score average? What type suits a phone number?

Show model answer

Average: REAL. Phone number: STRING, because leading zeros matter and arithmetic is inappropriate.

8.1 · Selection · 06

CASE selects a matching value

  • IF can test a Boolean expression or a range.
  • CASE is useful when one value selects among discrete choices.
  • The optional OTHERWISE branch handles unmatched values.
CASE OF Choice
    1 : OUTPUT "Add"
    2 : OUTPUT "Search"
    OTHERWISE OUTPUT "Invalid choice"
ENDCASE
Check your understanding

What is output for Choice = 3?

Show model answer

Invalid choice. Only 1 and 2 have matching branches.

8.1 · Iteration · 08

Choosing a loop

  • FOR suits a known number of repetitions.
  • WHILE tests before the body and may run zero times.
  • REPEAT tests after the body and runs at least once.
LoopCondition meaning
FOR Index ← 1 TO 5Execute for indexes 1, 2, 3, 4, 5
WHILE Score < 0 DOContinue while the condition is TRUE
REPEAT … UNTIL Score >= 0Stop when the condition becomes TRUE
Check your understanding

Which loop naturally fits prompting until input is valid?

Show model answer

REPEAT…UNTIL. Input must be requested at least once; stop when the valid condition is TRUE.

8.1 · Loop conditions · 10

Pre-condition and post-condition loops

  • WHILE tests before the body.
  • REPEAT tests after the body.
  • The same starting value can lead to a different number of executions.
X ← 5
WHILE X < 3 DO
    X ← X + 1
ENDWHILE

X ← 5
REPEAT
    X ← X + 1
UNTIL X >= 3
Check your understanding

If X starts at 5, how many times does each body run?

Show model answer

WHILE runs zero times. REPEAT runs once and leaves X equal to 6.

8.1 · Nested control · 11

A validation loop

  • The stopping condition describes valid input.
  • Both lower and upper limits must be satisfied.
  • This example assumes the input is already an integer.
REPEAT
    OUTPUT "Enter score, 0 to 20"
    INPUT Score
UNTIL Score >= 0 AND Score <= 20
Check your understanding

Why use AND in UNTIL but OR in a rejection condition?

Show model answer

A valid value must meet both limits. An invalid value only needs to violate one limit.

Teacher notes / 教师提示

Type checking is a separate requirement. In classroom Python, catch a conversion error before checking the numeric range.

8.1 · Scope and maintainability · 19

Local and global scope

  • A local variable is accessible within its subprogram.
  • A global variable can be accessed across the program in its declared scope.
  • Prefer parameters and return values when they make dependencies clearer.
Check your understanding

Why is changing an unrelated global Total inside a function risky?

Show model answer

Other parts of the program may depend on Total. The side effect makes behaviour harder to trace and reuse.

Teacher notes / 教师提示

Maintenance checklist: meaningful names; short subprograms; comments explaining non-obvious purpose; consistent indentation. Avoid comments that merely repeat every line.

Does ROUND(RANDOM() * 6, 0) model a fair six-sided die?

8.2 · Two-dimensional arrays · 26

Nested iteration through a 2D array

  • Rows identify students; columns identify quiz attempts.
  • Use nested iteration to visit every cell.
  • Reset a row total inside the outer loop, before the inner loop.
DECLARE Mark : ARRAY[1:3, 1:2] OF INTEGER
// Assume Mark has already been populated
FOR Student ← 1 TO 3
    Total ← 0
    FOR Quiz ← 1 TO 2
        Total ← Total + Mark[Student, Quiz]
    NEXT Quiz
    OUTPUT Total
NEXT Student
Check your understanding

How many additions are performed for 3 students and 2 quizzes?

Show model answer

Six additions. Each of the three row totals receives two values.

Teacher notes / 教师提示

Assume all array values have been populated before this fragment. Ask what happens if Total is initialised only once before both loops.

Writing persistent data

  • Open the file in WRITE mode before writing.

8.3 · File handling · 29

Reading a file until the end

  • Variables normally disappear when a program finishes; files preserve data.
  • Open a file in the intended mode, read or write, then close it.
  • Writing to a file may replace its previous contents.
OPENFILE "scores.txt" FOR READ
WHILE NOT EOF("scores.txt") DO
    READFILE "scores.txt", Line
    OUTPUT Line
ENDWHILE
CLOSEFILE "scores.txt"
Check your understanding

What must be checked before reading repeatedly to the end of a file?

Show model answer

Use an end-of-file check so the program does not attempt to read past the final line.

Teacher notes / 教师提示

Writing counterpart: OPENFILE "result.txt" FOR WRITE; WRITEFILE "result.txt", Line; CLOSEFILE "result.txt". Student task: read a name, save it, reopen and display it.
