启用时记录什么 / What is collected when enabled

记录网页浏览次数（PV），以及最近访问的最多 10 个不同 IP 地址和最后访问时间。同一 IP 再次访问会更新列表位置；刷新页面会增加浏览次数。浏览次数不是独立访客人数，IP 也不等于一个人。

记录通过浏览器脚本完成，关闭脚本、选择退出或网络拦截会使统计不完整。课件内部翻页、嵌入页面和直接下载 PDF 不另外计数。

We count page loads and keep a current list of up to ten distinct IP addresses with their most recent visit time. Repeat visits update the same entry. Counts are approximate and are not unique-person counts.

用途、访问权限与保存 / Purpose, access and retention

用于了解课程网站的使用情况和排查异常访问。浏览器仅发送页面路径，不发送 URL 查询参数、来源页面、姓名或联系方式；IP 由统计服务器从网络请求中获取。总浏览次数可以公开，完整 IP 列表仅管理员验证密码后可见。

统计服务部署在 Cloudflare Workers 与 D1。当前 IP 列表超过 10 项时淘汰最久未访问的一项；不保存逐次访问历史。数据库备份和服务商基础日志按其自身规则保留，不能保证被淘汰的 IP 立即从备份中消失。

Statistics use Cloudflare Workers and D1. Full IP addresses are restricted to the administrator. The live list retains at most ten entries; provider backups and infrastructure logs have their own retention policies. No advertising cookies or visitor profiles are created by this feature.
