两种系统对比 / System Comparison

特征 / Feature IECB系统 / IECB System 传统系统 / Conventional System
基础 / Base 2^n (二进制) 10^n (十进制)
转换系数 / Conversion 1024 1000
名称 / Names KiB, MiB, GiB, TiB KB, MB, GB, TB
1 KiB/KB 1,024 bytes 1,000 bytes
1 MiB/MB 1,048,576 bytes 1,000,000 bytes
1 GiB/GB 1,073,741,824 bytes 1,000,000,000 bytes

实际影响 / Practical Impact

  • 买了1TB硬盘，操作系统实际显示约 931 GiB。
  • 这不是质量问题，而是硬盘厂商(10^n)与操作系统(2^n)的计算方式不同。

选择原则 / Selection Principles

  • 技术计算: 精确场景，优先使用 IECB 系统 (MiB, GiB)。
  • 日常交流: 为方便理解，可使用传统系统 (MB, GB)。
  • 正式文档: 为避免混淆，必须明确指定使用的系统标准。

📈 关键差异 / Key Differences

  • 1 GB vs 1 GiB 相差 73,741,824 bytes (~7.3%)。
  • 单位越大，差异越显著：1 TB vs 1 TiB 相差约 99 GB (~9.9%)。
