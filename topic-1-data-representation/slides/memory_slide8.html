图像文件大小计算
Image File Size Calculation
📷图像文件大小 = 宽度 × 高度 × 色彩深度

📉参数详解 / Parameter Details

  • 图像分辨率 / Image Resolution: 宽度 × 高度 (像素)
    • 1920 × 1080 (Full HD)
    • 3840 × 2160 (4K)
    • 500 × 500 (Square)
  • 色彩深度 / Color Depth: 每像素的位数 (Bits per pixel)
    • 1-bit: 黑白 / B&W
    • 8-bit: 256 色
    • 24-bit: 16.7M 色 (真彩色)
    • 32-bit: 24-bit + Alpha通道

🔢计算步骤 / Calculation Steps

Step 1: 计算像素总数 = 宽度 × 高度

Step 2: 计算总位数 = 像素数 × 色彩深度

Step 3: 转换为字节 = 总位数 ÷ 8

Step 4: 转换为KiB = 字节数 ÷ 1024

📈实际计算示例 / Practical Example

问题/Problem: 查找宽度500、高度500的位图图像的大小，色彩深度为24位。 Find the size of a 500x500 bitmap image with a 24-bit color depth.

方法一 / Method 1:

1. (500×500×24) = 6,000,000 bits

2. 6,000,000 ÷ 8 = 750,000 bytes

3. 750,000 ÷ 1024 = 732.42 KiB

方法二 / Method 2:

1. 24 bits = 3 bytes

2. (500×500×3) = 750,000 bytes

3. 750,000 ÷ 1024 ≈ 732 KiB

答案 / Answer: ≈ 732 KiB
