声音文件大小计算 / Sound File Size Calculation

基本公式 / Basic Formulas

🎵 单声道音频 / Mono Audio:

文件大小 = 采样率 × 采样分辨率 × 时间长度 File Size = Sample Rate × Sample Resolution × Time Length

🎶 立体声音频 / Stereo Audio:

文件大小 = 采样率 × 采样分辨率 × 时间长度 × 2 File Size = Sample Rate × Sample Resolution × Time Length × 2

计算步骤 / Calculation Steps

1. 确定参数 / Determine parameters:
采样率 (Sample rate), 采样分辨率 (Resolution), 时间长度 (Time), 声道数 (Channels).

2. 应用公式 / Apply formula:
总位数 = 采样率 × 分辨率 × 时间(秒) × 声道数

3. 单位转换 / Unit conversion:
字节(Bytes) = 总位数 ÷ 8
KiB = 字节 ÷ 1024

参数详解 / Parameter Details

采样率 / Sample Rate (Hz)

  • 8,000 Hz: 电话质量 / Phone quality
  • 44,100 Hz: CD质量 / CD quality
  • 48,000 Hz: 专业录音 / Pro recording
  • 96,000 Hz: 高保真 / High-fidelity

采样分辨率 / Sample Resolution (bit)

  • 8-bit: 低质量 / Low quality
  • 16-bit: CD质量 / CD quality
  • 24-bit: 专业质量 / Professional quality

实际计算示例 / Practical Examples

示例1 - 单声道 / Example 1 - Mono

问题: 3分钟单声道音频, 44.1kHz采样率, 16-bit分辨率

44,100 × 16 × 180s × 1 = 127,008,000 bits
127,008,000 ÷ 8 = 15,876,000 bytes
15,876,000 ÷ 1024 ÷ 1024 = 15.1 MiB

示例2 - 立体声 / Example 2 - Stereo

问题: 1分钟立体声音频, 48kHz采样率, 24-bit分辨率

48,000 × 24 × 60s × 2 = 138,240,000 bits
138,240,000 ÷ 8 = 17,280,000 bytes
17,280,000 ÷ 1024 ÷ 1024 = 16.5 MiB
