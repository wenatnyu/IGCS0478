练习1 - 图像计算 / Practice 1 - Image Calculation

一张照片的分辨率为1920×1080像素, 使用24位色彩深度。计算文件大小(以MiB为单位)。
A photo has a resolution of 1920x1080 pixels and uses 24-bit color depth. Calculate the file size in MiB.

1. Pixels: 1920 × 1080 = 2,073,600

2. Total bits: 2,073,600 × 24 = 49,766,400 bits

3. Bytes: 49,766,400 ÷ 8 = 6,220,800 bytes

4. KiB: 6,220,800 ÷ 1024 = 6,075 KiB

5. MiB: 6,075 ÷ 1024 = 5.93 MiB

练习2 - 音频计算 / Practice 2 - Audio Calculation

一首立体声歌曲长度4分钟, 采样率为44.1kHz, 16位采样分辨率。计算文件大小(以MiB为单位)。
A stereo song is 4 minutes long, with 44.1kHz sample rate and 16-bit sample resolution. Calculate file size in MiB.

1. Time: 4 × 60 = 240 seconds

2. Total bits: 44,100 × 16 × 240 × 2 = 338,688,000 bits

3. Bytes: 338,688,000 ÷ 8 = 42,336,000 bytes

4. KiB: 42,336,000 ÷ 1024 = 41,344 KiB

5. MiB: 41,344 ÷ 1024 = 40.38 MiB

📊

练习3 - 数据库计算 / Practice 3 - Database Calculation

一个员工数据库含3000条记录, 每条记录占用120字节。计算数据库的大小(以KiB为单位)。
An employee database has 3000 records, each record takes 120 bytes. Calculate database size in KiB.

1. Total bytes: 3000 × 120 = 360,000 bytes

2. KiB: 360,000 ÷ 1024 = 351.56 KiB

练习4 - 视频计算 / Practice 4 - Video Calculation

一个10秒的视频, 分辨率1280×720, 24位色彩, 每秒30帧。不考虑音频和压缩, 计算文件大小(以GiB为单位)。
A 10s video, 1280x720, 24-bit color, 30fps. Ignoring audio/compression, calculate file size in GiB.

1. Bytes/frame: 1280×720 × 24 ÷ 8 = 2,764,800 bytes

2. Total bytes: 2,764,800 × 30fps × 10s = 829,440,000 bytes

3. KiB: 829,440,000 ÷ 1024 = 810,000 KiB

4. MiB: 810,000 ÷ 1024 = 791.02 MiB

5. GiB: 791.02 ÷ 1024 = 0.77 GiB

重要提醒 / Important Reminders

始终使用1024作为转换系数 / Always use 1024 as conversion factor • 注意单位转换的准确性 / Pay attention to unit conversion accuracy
