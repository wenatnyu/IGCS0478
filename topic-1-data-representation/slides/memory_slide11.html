知识总结 / Summary

1️⃣ 基本存储单位 / Basic Storage Units
  • 1 Byte = 8 Bits
  • 1 Nibble = 4 Bits (1 Byte = 2 Nibbles)
  • 字节是内存度量的基本单位 / Byte is the basic unit for memory measurement
2️⃣ IECB 系统与传统系统 / IECB vs Conventional Systems
  • IECB: 使用 2ⁿ, 转换系数 1024 (e.g., KiB, MiB)
  • 传统 / Conventional: 使用 10ⁿ, 转换系数 1000 (e.g., KB, MB)
  • 技术计算必须使用IECB系统 / Technical calculations must use IECB system
3️⃣ 文件大小计算公式 / File Size Calculation Formulas
🖼️ 图像文件 / Image Files:
文件大小 = 宽度 × 高度 × 色彩深度
File Size = Width × Height × Color Depth
🎵 音频文件 / Audio Files:
单声道 / Mono: 采样率 × 分辨率 × 时间
Stereo / 立体声: 采样率 × 分辨率 × 时间 × 2
✳️ 计算与转换 / Calculation & Conversion
计算步骤 / Calculation Steps:
  1. 计算总位数 / Calculate total bits
  2. 转换为字节 (÷ 8) / Convert to bytes (÷ 8)
  3. 转换为更大单位 (÷ 1024) / Convert to larger units (÷ 1024)
关键转换 / Key Conversions:
  • 1024 bytes = 1 KiB
  • 1024 KiB = 1 MiB
  • 1024 MiB = 1 GiB
  • 1024 GiB = 1 TiB
✅ 重要原则 / Important Principles
做题注意事项 / Exam Guidelines:
  • 始终使用 1024 作为乘数，不是1000
  • 答案必须使用题目指定的单位 (注意 KiB vs KB)
  • 保留适当的小数位数 / Keep appropriate decimal places
⚙️ 实际应用 / Practical Applications:
  • 系统内存管理 / System memory management
  • 文件存储规划 / File storage planning
  • 网络传输速度计算 / Network transmission speed calculation
总结结论 / Final Conclusions
  • 理解存储单位系统对精确计算至关重要。
  • 掌握文件大小计算有助于优化系统性能。
学习成果 / Learning Outcomes
  • 能够区分两种存储单位系统。
  • 能够计算图像和音频文件大小。
