Run-Length Encoding 算法 / RLE Algorithm
🔄 RLE 算法定义 / Definition

Run-Length Encoding (游程编码):

减少一串相邻的、相同数据的大小。

Reduces the size of a string of adjacent, identical data.

适用场景 / Use Cases:

图像中重复的颜色、文本中重复字符。

Repeated colors in images, repeated characters in text.

📊 编码原理 / Principle

双值编码系统 / Two-Value System:

  • 第一个值: 相同数据项的数量 (次数)
  • First Value: Number of identical data items (count)
  • 第二个值: 数据项的代码 (内容)
  • Second Value: Code of the data item (content)
🔢 算法步骤 / Algorithm Steps

1. 数据扫描 / Data Scanning: 从左到右扫描输入数据，识别连续序列。

Scan input data from left to right, identify consecutive sequences.

2. 计数统计 / Count Statistics: 计算序列长度，记录字符值。

Calculate length of each sequence, record character value.

3. 编码输出 / Encoding Output: 输出格式为 [数量][字符代码]，常使用ASCII码。

Output format: [Count][Character Code], using ASCII.

📋 具体实例 / Specific Example

原始数据: 

aaaaabbbbccddddd

分析: aaaaa → 5个'a', bbbb → 4个'b', cc → 2个'c', ddddd → 5个'd'

编码结果: (使用ASCII码) 

"05 97 04 98 02 99 05 100"

压缩效果: 原始16字节 → 压缩后8字节 (压缩率50%)

✅ 高效情况 / Effective

长连续重复：黑白图像、简单图形、重复文本。

Long runs: black-white images, simple graphics, repetitive text.

⚠️ 低效情况 / Ineffective

无重复数据：随机数据、复杂图像、加密数据。

No repetition: random data, complex images, encrypted data.

🚀 性能特点 / Performance

O(n) 时间, O(1) 空间, 实现简单。

O(n) time, O(1) space, simple to implement.

🖼️ 应用领域 / Applications

图像处理 (BMP, PCX), 视频编码 (部分环节), 数据存储 (索引压缩)。
