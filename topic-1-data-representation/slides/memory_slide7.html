文件大小计算原理 / File Size Calculation Principles

  • 基本原理 / Basic Principles: 文件大小 = 数据量 × 每单位数据的存储大小 / File size = Data quantity × Storage size per unit data
  • 不同类型的文件有不同的计算方法 / Different file types have different calculation methods

🖼️ 图像文件 / Image Files

基本公式 / Basic Formula

文件大小 = 宽度 × 高度 × 色彩深度

File Size = Width × Height × Color Depth

参数说明 / Parameter Explanation

  • 宽度/高度: 像素数量 / Number of pixels
  • 色彩深度: 每像素的位数 / Bits per pixel
  • 结果单位: 位(bits) / Result unit: bits

🎵 音频文件 / Audio Files

单声道公式 / Mono Formula

文件大小 = 采样率 × 采样分辨率 × 时间

File Size = Sample Rate × Resolution × Time

立体声公式 / Stereo Formula

文件大小 = ... (单声道) × 2

File Size = ... (Mono) × 2

参数说明 / Parameter Explanation

  • 采样率: 每秒采样次数(Hz)
  • 采样分辨率: 每样本的位数(bits)
  • 时间: 秒数 / seconds
  • 结果单位: 位(bits) / Result unit: bits

📄 文本文件 / Text Files

基本公式 / Basic Formula

文件大小 = 字符数 × 每字符字节数

File Size = # of Chars × Bytes per Char

单位转换与提醒 / Notes & Reminders

  • 每字符字节数: 取决于编码 (e.g., ASCII = 1 byte, UTF-8 = 1-4 bytes).
  • 计算结果: 通常为位(bits).
  • 单位换算:
    • 1 Byte = 8 bits
    • 1 KiB = 1024 Bytes
  • 重要: 存储换算请用 1024, 并注意题目要求的最终单位。
