Section 5 Glossary

Bilingual Visual Dictionary | 互联网与网络安全核心词汇表

Internet & WWW / 基础概念

Internet 互联网

The world-wide interconnection of networks; makes use of TCP and IP protocols.

全球互联的网络系统；使用 TCP 和 IP 协议。

Infrastructure
World Wide Web (WWW) 万维网

A massive collection of web pages based on hypertext transfer protocols (http/https).

基于超文本传输协议（HTTP/HTTPS）的海量网页集合。

Software
Domain Name Server (DNS) 域名解析服务器

A server that translates domain names (URLs) into IP addresses that computers can understand.

将域名（URL）转换为计算机可理解的 IP 地址的服务器。

Protocol
Cookie Cookie (网络曲奇)

A small text file sent from a website to a browser to remember user preferences.

网站发送到浏览器的小文本文件，用于记住用户偏好设置。

Data

Digital Currency / 数字货币

Blockchain 区块链

A decentralized database where all transactions are stored across interconnected computers (no central server).

一种去中心化数据库，所有交易存储在互联的计算机网络中（无中央服务器）。

Technology
Cryptocurrency 加密货币

A digital currency that uses a decentralized network to monitor transactions (e.g., Bitcoin).

使用去中心化网络监控交易的数字货币（例如比特币）。

Finance
Proof-of-Work 工作量证明

Algorithm used to confirm transactions and create new blocks; performed by 'miners'.

用于确认交易并创建新区块的算法；由“矿工”执行。

Algorithm

Cyber Security Threats / 网络威胁

Brute Force Attack 暴力破解攻击

Trial and error method to crack passwords by trying all combinations.

通过尝试所有组合来破解密码的试错法。

Attack
Phishing 网络钓鱼

Sending legitimate-looking emails to trick recipients into giving personal details.

发送看似合法的电子邮件，诱骗收件人提供个人信息。

Social Engineering
DDoS Attack 分布式拒绝服务攻击

Flooding a website with fake requests from many computers to disrupt service.

利用多台计算机发送大量虚假请求，淹没网站以中断服务。

Attack
Malware 恶意软件

Umbrella term for viruses, worms, trojans, spyware, adware, and ransomware.

病毒、蠕虫、木马、间谍软件、广告软件和勒索软件的统称。

Software
Pharming 嫁接攻击 (DNS投毒)

Redirecting a user to a fake website without their knowledge (often via DNS poisoning).

在用户不知情的情况下将其重定向到假网站（通常通过 DNS 投毒）。

Attack

Security Solutions / 安全防御

Firewall 防火墙

Hardware or software that filters incoming and outgoing traffic based on rules.

根据规则过滤传入和传出流量的硬件或软件。

Defense
SSL Certificate SSL 证书

Digital certificate used to authenticate a website and enable secure HTTPS connection.

用于验证网站身份并启用安全 HTTPS 连接的数字证书。

Encryption
Biometrics 生物识别

Authentication using unique human characteristics (fingerprint, retina, voice).

使用独特的人体特征（指纹、视网膜、声音）进行身份验证。

Authentication
Two-step Verification 双重验证

Requires two methods of verification to prove user identity (e.g., Password + SMS Code).

需要两种验证方法来证明用户身份（例如：密码 + 短信验证码）。

Authentication
