Trace a running total

The list is [4, 7, 2]. Initialise Total to zero. Each pass adds the current item and records the new value.

Total ← 0
FOR Index ← 1 TO 3
    Total ← Total + Values[Index]
NEXT Index
OUTPUT Total
IndexValue addedTotal after addition
144
2711
3213

Output: 13. A count increases by one for each item; a total increases by the item’s value. Average = Total / Count, provided Count is not zero.

Step through the trace

Follow the same algorithm one addition at a time.

Initial state: Total = 0. No values have been added.

Find a value using linear search

Found ← FALSE
Position ← 0
FOR Index ← 1 TO 3
    IF Values[Index] = Target AND NOT Found
      THEN
        Found ← TRUE
        Position ← Index
    ENDIF
NEXT Index
OUTPUT Found, Position

This records the first match, or position 0 if absent. For Target = 7, Found is TRUE and Position is 2.

From a problem to a design

For a class marks system: input names and marks; validate the marks; calculate total, average, highest and lowest; output the report; store results in a file. A structure diagram divides these tasks hierarchically. A flowchart shows execution order and decisions.

Flowchart symbols: oval = start/stop; parallelogram = input/output; rectangle = process; diamond = decision; a rectangle with double vertical edges = subroutine; arrows = direction of control.

Design a marks algorithm

Input five integer marks in the range 0–100. Reject and re-enter invalid marks. Output the total, average, maximum and minimum.

Reveal solution guidance

Initialise Total to 0. Validate each input with a loop before using it. Set Min and Max from the first accepted mark; update them on subsequent marks. Add each mark to Total. Output Total, Total / 5, Max and Min. Test all-equal marks, extreme marks and invalid input.
