8 / See scores_model.py.
This model uses Python zero-based indexing. linear_search returns -1 when absent;
the classroom pseudocode uses one-based arrays and 0 when absent. Do not mix them.
Statistics initialises highest to the first item, so negative-only data also work.
All-zero data: 0, 0, 0. All-twenty data: 100, 20, 20.
Two-dimensional example: [[4,7],[2,20],[0,6]] gives row totals [11,22,6].
