对称加密

Symmetric Encryption

对称加密定义

  • 使用加密密钥进行加密过程，同一密钥用于加密和解密数据。 Uses an encryption key for the encryption process, the same key is used for both encrypting and decrypting data.

核心特点

  • 🔑 单一密钥系统 (Single Key System): 发送方和接收方使用相同的秘密密钥，密钥必须事先在双方之间安全共享。 Sender and receiver use the same secret key. Key must be securely shared between parties in advance.
  • ⚙️ 加密解密过程 (Encryption/Decryption Process):
    加密: Plaintext + Secret Key → Ciphertext
    解密: Ciphertext + Secret Key → Plaintext

优点 (Advantages)

  • ⚡ 速度快 (Fast Speed): 加密和解密速度非常快，适合大量数据处理。 Very fast encryption and decryption, suitable for large data processing.
  • 💪 效率高 (High Efficiency): 计算复杂度低，资源消耗少。 Low computational complexity, minimal resource consumption.
  • 💰 成本低 (Low Cost): 对硬件要求低，容易实现。 Low hardware requirements, easy to implement.

缺点 (Disadvantages)

  • ⚠️ 密钥分发困难 (Key Distribution Problem): 如何安全地将密钥传递给通信对方是个难题。 Securely transmitting the key to communication partners is challenging.
  • 🔒 密钥管理复杂 (Complex Key Management): 多个用户之间需要多个不同的密钥。 (n个用户需要 n(n-1)/2 个密钥) Multiple different keys needed between multiple users. (n users require n(n-1)/2 keys)
  • 🚫 不支持数字签名 (No Digital Signature Support): 无法确认数据的发送者身份。 Cannot verify sender's identity.

常见对称加密算法:

  • AES (Advanced Encryption Standard): 目前最广泛使用的标准
  • DES (Data Encryption Standard): 较早的加密标准
  • 3DES (Triple DES): 增强版DES
