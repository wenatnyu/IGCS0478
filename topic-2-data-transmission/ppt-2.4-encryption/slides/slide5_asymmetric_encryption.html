非对称加密

Asymmetric Encryption

📖 1. 非对称加密定义

使用公钥和私钥系统，两个不同的密钥分别用于加密和解密 Uses public key and private key system, two different keys are used separately for encryption and decryption

2. 密钥系统详解

🔓 公钥 (Public Key)

  • 对所有人可用，可以公开分享和发布Available to everyone, can be openly shared and distributed

  • 用于加密数据或验证数字签名Used for encrypting data or verifying digital signatures

🔐 私钥 (Private Key)

  • 只有用户可用，绝对保密，不对外公开Only available to the user, absolutely confidential, not disclosed publicly

  • 用于解密数据或生成数字签名Used for decrypting data or generating digital signatures

3. 工作原理

📨 数据加密流程 (Data Encryption Flow)

  1. 接收方拥有私钥，并将公钥发送给发送方Receiver owns private key and sends public key to sender
  2. 发送方使用公钥加密数据Sender encrypts data using public key
  3. 接收方使用私钥解密数据Receiver decrypts data using private key

📝 数字签名流程 (Digital Signature Flow)

  1. 发送方使用私钥对数据进行签名Sender signs data using private key
  2. 接收方使用公钥验证签名Receiver verifies signature using public key

4. 优点 (Advantages)

  • 🔒
    密钥分发安全 (Secure Key Distribution)Public keys can be safely transmitted openly, no need to pre-share keys
  • ✅
    数字签名支持 (Digital Signature Support)Can verify data origin and integrity
  • 🔍
    不可否认性 (Non-repudiation)Sender cannot deny having sent the data

5. 缺点 (Disadvantages)

  • ⚡
    速度较慢 (Slower Speed)Encryption/decryption is 100-1000 times slower than symmetric encryption
  • 💻
    计算复杂 (Computationally Complex)Requires more CPU resources and storage space
  • 💰
    成本较高 (Higher Cost)Higher hardware and software resource requirements

6. 常见算法

  • 📜
    RSA: 最广泛使用的非对称加密算法
  • 📜
    ECC: 椭圆曲线加密 (Elliptic Curve Cryptography)
  • 📜
    DSA: 数字签名算法 (Digital Signature Algorithm)
