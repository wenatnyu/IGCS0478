对称加密概念介绍

Symmetric Encryption Concepts

📚 对称加密定义

  • 对称加密是一种使用相同密钥进行数据加密和解密的加密方法。 Symmetric encryption is an encryption method that uses the same key for both encrypting and decrypting data.
  • 发送方和接收方必须共享同一个秘密密钥。 The sender and receiver must share the same secret key.
  • 这个密钥必须在通信双方之间安全地交换。 This key must be securely exchanged between the communicating parties.

⚙️ 加密解密过程

  • 加密过程 (Encryption Process):
    明文 + 密钥 → 密文
    Plaintext + Key → Ciphertext
  • 解密过程 (Decryption Process):
    密文 + 密钥 → 明文
    Ciphertext + Key → Plaintext

🔑 单一密钥系统 (Single Key System)

对称加密最重要的特征是使用🔑同一个密钥🔑进行加密和解密操作
The most important feature of symmetric encryption is using the same key for both encryption and decryption operations
