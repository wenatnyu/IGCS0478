10.1–10.2 · Foundations · 01

Boolean values and logic gates

  • Use 0 / 1 or FALSE / TRUE consistently.
  • A gate maps input values to one output.
  • NOT has one input; the other required gates have two inputs.
Check your understanding

How many input combinations are possible for three independent inputs?

Show model answer

2³ = 8 combinations, from 000 through 111.

10.2 · Gate functions · 08

Comparing the five two-input gates

  • AND: both 1. OR: at least one 1. XOR: exactly one 1.
  • NAND is NOT AND; NOR is NOT OR.
  • NOT reverses its single input: 0 → 1 and 1 → 0.

10.3 · Statement to expression · 10

An alarm problem statement

  • A = door sensor active; B = window sensor active; C = alarm disabled.
  • The alarm sounds if either sensor is active AND the alarm is not disabled.
  • Write the expression before drawing the circuit.
P = A OR B
Q = NOT C
X = P AND Q
Check your understanding

Write the alarm expression using A, B and C.

Show model answer

X = (A OR B) AND NOT C. OR is inclusive: both sensors may be active.

Teacher notes / 教师提示

For a circuit, connect A and B to OR; connect C to NOT; connect the two intermediate outputs to AND. Do not simplify away gates specified by the statement.

10.3 · Table to expression · 13

An expression from output-1 rows

  • For each output-1 row, create an AND term matching its input values.
  • Use NOT for a 0 input and the unchanged variable for a 1 input.
  • Join those row terms with OR.
Check your understanding

For two inputs, only 01 and 10 give output 1. Write an expression.

Show model answer

(NOT A AND B) OR (A AND NOT B). This has XOR behaviour; follow the requested form when drawing a circuit.

10.3 · Expression to circuit · 19

Constructing a circuit from an expression

  • Use at most two inputs per non-NOT gate.
  • Build longer expressions from a sequence of two-input gates.
  • For 2026–2028, draw the statement as given without simplification.
P = A AND B
Q = NOT A
R = Q AND C
X = P OR R
Check your understanding

How do you build (A AND B) OR (NOT A AND C)?

Show model answer

Create the two AND results separately, including NOT A, then feed their outputs into an OR gate.

10.3 · Independent practice · 20

Independent circuit task

  • Name every intermediate output.
  • Trace one test input through all gates.
  • Then complete the truth table and compare it with the problem statement.
Check your understanding

For (A AND B) OR (NOT A AND C), find X when A = 0, B = 1, C = 1.

Show model answer

P = 0, Q = 1, R = 1, X = 1. The unselected branch cannot change this OR result.

Teacher notes / 教师提示

Exit task: draw the circuit, enumerate all eight rows, then explain in words when X is 1. Homework: Hodder chapter 10 workbook then PMT 10. Full adders in the textbook are enrichment, not an extra 2026–2028 requirement.

10.3 · Review · 22

Logic-circuit checks

  • Use one input for NOT and two for each other required gate.
  • Label external inputs, intermediate results and the final output.
  • Keep all branches required by the original statement.
Check your understanding

What does a small circle on a gate’s output mean?

Show model answer

Inversion. It changes each 0 to 1 and each 1 to 0.
