From a scenario to a circuit

An alarm sounds when a door (A) or window (B) is open, and maintenance mode (C) is off. The expression is X = (A OR B) AND NOT C.

Connect A and B to an OR gate, C to a NOT gate, then connect both resulting signals to an AND gate. Preserve this structure when drawing the circuit; do not simplify the given expression.

Explore the circuit

Change any input to see the intermediate values and matching truth-table row.

Quick check

Choose one answer for every question, then check your answers. You can revise and try again.

1. For A = 1 and B = 1, what does A XOR B produce?

2. Which gate outputs 1 only when both inputs are 0?

3. How many rows does a complete three-input truth table need?

4. For A = 1, B = 0 and C = 1, what is (A OR B) AND NOT C?

Convert an expression to a circuit

Draw X = (A NAND B) OR C, and list X for inputs 000, 001, 010, 011, 100, 101, 110, 111.

Reveal solution guidance

Connect A and B to a NAND gate. Connect that output and C to an OR gate. The output sequence is 1, 1, 1, 1, 1, 1, 0, 1. Keep the NAND and OR gates exactly as specified.
