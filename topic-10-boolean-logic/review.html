Part 1: Standard Logic Gates and their Functions

Electronic circuits in computers and controlling devices are made up of thousands of logic gates . These gates take binary inputs (0 or 1) and produce a binary output. You must be able to identify and use the standard symbols for six specific logic gates.

1. The Six Logic Gates

According to the syllabus, the NOT  gate is the only single-input gate; all other gates are limited to two inputs .

  • NOT Gate:
  • Function:  The output is 1 if the input is 0 (it reverses the input).
  • Logic Expression:  X = NOT A
  • AND Gate:
  • Function:  The output is 1 if both  inputs A and B are 1.
  • Logic Expression:  X = A AND B
  • OR Gate:
  • Function:  The output is 1 if either  input A or input B, or both , are 1.
  • Logic Expression:  X = A OR B
  • NAND Gate (NOT AND):
  • Function:  The output is 1 if input A and input B are NOT both  1 (the exact opposite of the AND gate).
  • Logic Expression:  X = A NAND B
  • NOR Gate (NOT OR):
  • Function:  The output is 1 if neither  input A nor input B is 1 (the exact opposite of the OR gate).
  • Logic Expression:  X = A NOR B
  • XOR Gate (Exclusive OR):
  • Function:  The output is 1 if inputs are different (i.e., input A is 1 AND input B is 0, OR input A is 0 AND input B is 1).
  • Logic Expression:  X = A XOR B

(Note: While some resources use Boolean algebra notation like A · B or A + B, the IGCSE exam primarily requires you to use the standard logic wording like A AND B.)

Part 2: Truth Tables

A truth table  is used to trace and check the output from a logic gate or a complex logic circuit for every possible combination of inputs.

1. Number of Inputs

  • The syllabus states that logic circuits will be limited to a maximum of three inputs and one output .
  • For 2 inputs  (e.g., A and B), there are 2² = 4 possible binary combinations (00, 01, 10, 11).
  • For 3 inputs  (e.g., A, B, and C), there are 2³ = 8 possible binary combinations (000, 001, 010, 011, 100, 101, 110, 111).

2. Completing Truth Tables from Logic Circuits

When dealing with a complex logic circuit with 3 inputs, it is best practice to split the circuit into parts and use intermediate values  (e.g., P, Q, R) to trace the logic step-by-step before finding the final output (X).

  1. Add intermediate columns to your truth table for every logic gate's output before the final gate.
  2. Work through the 8 combinations systematically row by row.

Part 3: Logic Expressions, Circuits, and Problem Statements

You must be able to seamlessly convert between a problem statement, a logic expression, a truth table, and a logic circuit. Crucial Syllabus Rule:  Circuits must be drawn exactly for the statement/expression given, without simplification .

1. From Logic Circuit to Logic Expression

  • Start from the inputs and work towards the output, writing the expression for each gate in brackets.
  • Example:  If gate 1 is (A AND B) and gate 2 is (B OR C), and they are connected by an XOR gate, the final expression is: (A AND B) XOR (B OR C).

2. From Truth Table to Logic Expression

  • To write a logic expression from a truth table, you only need to consider the rows where the final output is 1 .
  • Example:  If the output is 1 only when A=1 and B=0, the expression is A AND NOT B. If there are multiple rows where the output is 1, write the expression for each row and join them together with OR .

3. From Problem Statement to Logic Circuit/Expression

Real-world scenarios are often given in text. You must extract the logic.

  • Step 1:  Identify the inputs and conditions. Usually, a condition being met (e.g., "temperature > 80°C") equals 1, and not met equals 0.
  • Step 2:  Look for the key connecting words: AND , OR , and NOT .
  • Example Statement:  "The alarm (X) sounds if the turbine speed is > 1000 rpm (S) AND the bearing temperature is > 80°C (T)."
  • Logic Expression:  X = (S AND T).
  • Step 3:  Draw the circuit by creating intermediate logic gates for the terms inside brackets first, and then linking them together with the final gates specified by the expression.

4. From Logic Expression to Logic Circuit

  1. Break the expression down into parts using the brackets as a guide.
  2. Example:  ((A NOR B) AND C) NAND (A OR NOT B)
  3. Draw a NOR gate for A and B.
  4. Connect its output and input C into an AND gate.
  5. Draw a NOT gate for B, and connect it with A into an OR gate.
  6. Connect the outputs of steps 2 and 3 into a final NAND gate.

Revision Tips for Topic 10:

  • Memorize the 6 gate symbols and their exact truth tables.  Be extremely careful not to confuse NAND with NOR, or OR with XOR.
  • Always use standard sequence for 3-input truth tables (000, 001, 010... up to 111) to ensure you don't miss any combinations.
  • When completing a truth table for an exam, always use working space (intermediate columns)  to avoid silly calculation errors.
