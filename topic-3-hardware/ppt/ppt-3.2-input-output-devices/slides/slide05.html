QR码技术详解 / QR Code Technology Deep Dive

QR码 (Quick Response Code) 是一种二维矩阵条码，由深浅不同的小正方形 (像素) 组成，能够存储大量数据并具有错误纠正能力。
QR Code is a 2D matrix barcode composed of dark and light small squares (pixels) that can store large amounts of data with error correction capability.

QR码结构分析 🔍

  • ① 定位模块 / Position Detection Patterns

    三个大方块 (左上、右上、左下角)，用于确定正确的扫描角度。
    Three large squares (top-left, top-right, bottom-left) to determine correct scanning angle.

  • ② 像素矩阵 / Pixel Matrix Structure

    由深浅小正方形组成 (21×21至177×177)，每个像素代表二进制位。
    Composed of dark/light squares (21×21 to 177×177), each representing binary bits.

  • ③ 静止区 / Quiet Zone

    围绕QR码的空白区域，确保扫描器能识别边界。
    White space surrounding the code, ensuring scanner can identify boundaries.

  • ④ 对齐模块 / Alignment Patterns

    小型方块图案，辅助精确对齐和纠错。
    Small square patterns assisting precise alignment and error correction.
